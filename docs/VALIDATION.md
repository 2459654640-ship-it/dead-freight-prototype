# 成品素材版本验证

Godot 4.6.3 standard / Linux x86_64。

- 功能回归：52 项检查，0 失败。包含真实移动、碰撞、AI 视线与射击、搜刮、背包防重复转移、治疗中断、换弹守恒、原始武器动画、暂停及撤离持久化。
- 特别回归：成品模型的 `_col` 名称曾触发自动生成碰撞体，造成玩家被推走和搜刮射线受阻。已禁用导入美术自带碰撞，保留显式游戏碰撞体，新增检查覆盖此情况。
- M4 原始换弹动画通过武器骨骼变换检查，不再使用上一版手工弹匣动画。
- 角色材质使用原始作者的漫反射/法线贴图；布料金属与粗糙度按 Godot 管线修正。
- 实际图形检查：Xorg dummy + Mesa llvmpipe OpenGL 4.5，检查菜单、室内外、近景人物、瞄准、换弹和背包。
- 软件渲染仅验证画面正确性，不代表玩家显卡帧率。

角色的高质量动画重定向、关卡整体美术密度、更多物品模型与商业级音画打磨仍属于后续工作。
